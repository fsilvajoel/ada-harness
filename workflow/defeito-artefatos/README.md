# Artefatos de um defeito

Moldes dos arquivos que o workflow [defeito](../defeito.md) produz em `docs/defeitos/`.
Copie o molde, troque os `<...>` e apague o que não se aplica. A correção usa os moldes da feature
([feature-artefatos/](../feature-artefatos/README.md)) em `docs/plano/D<n>/`.

| Arquivo | Molde | Quem escreve |
|---|---|---|
| `docs/defeitos/D<n>.md` | [defeito.md](defeito.md) | orquestrador |
| `docs/defeitos/README.md` | [indice.md](indice.md) | orquestrador |
